# PhotoFrame

Лёгкий виджет рабочего стола для Windows — фоторамка со слайдшоу.

## Возможности

- **Слайдшоу** — автоматическая смена фото с настраиваемым интервалом (5 сек — 15 мин)
- **Рамки** — дерево, металл, золото, чёрный матовый, анимированный градиент
- **Формы** — прямоугольник, скруглённый, круг (настоящий, не просто `CornerRadius`)
- **Толщина рамки** — тонкая / стандарт / толстая / очень толстая
- **Случайный порядок** / по порядку, навигация кнопками
- **Прозрачность** — от 50% до 100%
- **Drag & Drop** — перетащите папку с фото на виджет
- **Всегда поверх** остальных окон
- **Автозапуск** с Windows
- **Переносимость** — портативная версия, настройки в `%AppData%/PhotoFrame`

## Сборка

```bash
# Или установить через Inno Setup:
# installer/setup.iss
```

Требования: .NET 8 SDK

## Использование

1. Запустите `PhotoFrame.exe`
2. Нажмите **правую кнопку мыши** → «Выбрать папку» с фотографиями
3. Настраивайте интервал, рамку, форму и т.д. через контекстное меню

### Горячие клавиши

| Клавиша    | Действие              |
|------------|-----------------------|
| Пробел     | Следующее фото        |
| Backspace  | Предыдущее фото       |
| Esc        | Закрыть виджет        |
